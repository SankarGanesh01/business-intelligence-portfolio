# Business Intelligence & Data Analytics Portfolio

A collection of Business Intelligence and Data Analytics projects using Power BI, SQL, Excel, and public datasets.

This repository brings together three separate assignments demonstrating database design, data exploration, financial calculations, data visualisation, and dashboard development.

## Projects

### 01. Online Retail Sales Analytics

**Tools:** SQL, Microsoft Power BI

A retail analytics project using manually entered sample records in a relational SQL database connected to Power BI.

**Focus areas**
- Relational database design and primary/foreign keys
- SQL queries for sales, profit, and product performance
- Sales comparisons by month, product, city, and region
- Customer purchase patterns and payment preferences
- Power BI dashboard design and filtering

**Data note:** The records were manually entered as sample data. The results are illustrative and do not represent actual retail business performance.

[Open project folder](01-online-retail-sales/)

### 02. Malaysia Crime Data Analysis

**Tools:** Microsoft Power BI, public datasets

A data visualisation project using Malaysian crime statistics obtained from the official data.gov.my catalogue.

**Focus areas**
- Exploring crime patterns by location, crime type, and year, where supported by the dashboard
- Presenting crime statistics through Power BI visualisations
- Working with publicly available government data
- Documenting data sources and limitations

**Data note:** The project uses public statistical data. Interpretations should reflect the source definitions, reporting coverage, and time periods of the underlying datasets.

[Open project folder](02-malaysia-crime-analysis/)

### 03. Finance Sales Dashboard

**Tools:** Microsoft Power BI, Microsoft Excel, DAX

A financial sales reporting assignment based on the provided `Finance.xlsx` workbook.

**Focus areas**
- Calculated Profit and Profit Margin
- Sales and profit comparisons across years, products, segments, and discount bands
- Country-level sales and profitability visualisations
- Waterfall charts for sales and profit progress
- Interactive filtering and report navigation

**Data note:** The workbook was supplied for an academic assignment. The dashboard should be understood in that context rather than presented as an analysis of the user's own business.

[Open project folder](03-finance-sales-dashboard/)

## Tools and Skills

- **Power BI:** Interactive reports, charts, slicers, and dashboard layout
- **SQL:** Relational tables, constraints, data insertion, and analytical queries
- **DAX:** Calculated columns and measures
- **Excel:** Data preparation and workbook-based analysis
- **Data analytics:** Trend analysis, comparisons, KPI reporting, and visual communication

## How to View the Projects

1. Open a project folder.
2. Read its README for the business context, tools, and data limitations.
3. View the dashboard screenshots, where available.
4. Download the `.pbix` file and open it using Microsoft Power BI Desktop to interact with the report.

Power BI reports are not interactive directly within GitHub.

## Data and Reproducibility

The three projects use different data sources and should be interpreted separately. The retail project uses manually entered sample data, the crime project uses public Malaysian statistical data, and the finance dashboard uses an assignment-provided Excel workbook.

The availability of a `.pbix` file alone does not guarantee that a report can be refreshed. Some reports may depend on local files, database connections, or data-source credentials.

## Project Scope

These projects demonstrate applied Business Intelligence and Data Analytics skills through academic assignments. They are presented as a portfolio of practical work, not as commercial deployments or verified business consulting engagements.
