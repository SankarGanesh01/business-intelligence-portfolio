# SQL Scripts

This folder is intended for the SQL scripts used in the Online Retail Sales Analytics project.

## Intended Files

- `schema.sql` — Database and table definitions, including primary and foreign keys.
- `insert_sample_data.sql` — SQL statements for inserting the manually entered sample records.
- `analysis_queries.sql` — Queries for sales, profit, quantity sold, product performance, regions, customers, and payment methods.

Only add scripts that represent the SQL actually used or have been recreated and tested. The project uses sample data and does not represent real retail transactions.
