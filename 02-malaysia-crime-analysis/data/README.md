# Data Sources and Documentation

## Source Catalogue

All datasets for this project were obtained from the official Malaysian government data catalogue:

https://data.gov.my/data-catalogue

## 1. Crime by District

**Filename:** `crime_district.csv`

**Source:** https://data.gov.my/data-catalogue/crime_district

Contains crime statistics by geographical area, crime category, crime type, and year, subject to the publisher's definitions.

## 2. Population by District

**Filename:** `population_district.csv`

**Source:** https://data.gov.my/data-catalogue/population_district

Contains population estimates for administrative districts, with demographic breakdowns.

## 3. National Population

**Filename:** `population_malaysia.csv`

**Source:** https://data.gov.my/data-catalogue/population_malaysia

Contains national population statistics with demographic breakdowns.

## Data Handling

The CSV files are source data used or collected for the analysis. They are not included in this folder by default. Obtain the current files from the official catalogue if needed.

Before combining crime and population data, check the year, geographical identifiers, district boundaries, and definitions. Do not assume police districts and administrative districts are interchangeable.

## Attribution and Reuse

Credit data.gov.my and the original data publisher when using these datasets. Check the applicable licence and dataset metadata before redistribution.
